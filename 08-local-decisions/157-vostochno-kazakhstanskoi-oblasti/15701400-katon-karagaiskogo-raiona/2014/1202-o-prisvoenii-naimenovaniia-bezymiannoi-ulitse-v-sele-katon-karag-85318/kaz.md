# Катонқарағай ауылындағы атауы жоқ көшеге атау беру туралы

«Қазақстан Республикасының әкiмшiлiк–аумақтық құрылысы туралы» Казақстан Республикасының 1993 жылғы 8 желтоқсандағы Заңының 14-бабы 4) тармақшасына, «Қазақстан Республикасындағы жергiлiктi мемлекеттiк басқару және өзiн-өзi басқару туралы» Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңының 35-бабы 2-тармағына сәйкес, 2014 жылғы 3 қыркүйектегі Шығыс Қазақстан облыстық ономастикалық комиссияның қорытындысы негізінде және ауыл тұрғындарының пікірін ескере отырып, Катонқарағай ауылдық округінің әкімі ШЕШТІ:

<a id="p1"></a>

1. Катонқарағай ауылдық округiнің Катонқарағай ауылындағы атауы жоқ көшеге «Михаил Кильтер» атауы берiлсiн.

<a id="p2"></a>

2. Осы шешiмнiң орындалуын бақылау Катонқарағай ауылдық округi әкiмiнің орынбасары Б. Макишевке жүктелсiн.

<a id="p3"></a>

3. Осы шешiм алғашқы ресми жарияланған күнінен кейiн күнтiзбелiк он күн өткен соң қолданысқа енгiзiледi.

**Катонқарағай ауылдық округінің әкімі**

**А. Балтабаев**
