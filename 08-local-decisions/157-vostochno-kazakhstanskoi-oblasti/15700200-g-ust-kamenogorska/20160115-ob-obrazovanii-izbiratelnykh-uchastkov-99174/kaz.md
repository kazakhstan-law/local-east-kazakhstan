# Сайлау учаскелерін құру туралы

Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі «Қазақстан Республикасындағы сайлау туралы» Конституциялық Заңының 23-бабына сәйкес ШЕШТІ:

1. Осы шешімнің 1-қосымшасына сай сайлау учаскелері құрылсын.

2. Осы шешімнің 2-қосымшасына сай Өскемен қаласы әкімі шешімдерінің күші жойылсын деп танылсын.

3. Осы шешім оның алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`part001`](kaz/part001.md) | `!` Сайлау учаскелері |
| [`part002`](kaz/part002.md) | Өскемен қаласы әкімінің күші жойылған шешімдерінің тізбесі |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
