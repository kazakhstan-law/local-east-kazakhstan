# 2019-2021 жылдарға арналған Жаңа Бұқтырма кентінің бюджеті туралы

Қазақстан Республикасы Президентінің 2018 жылғы 28 желтоқсандағы № 821 «Шығыс Қазақстан облысының Зырян ауданын және Зырян қаласын Шығыс Қазақстан облысының Алтай ауданы және Алтай қаласы деп қайта атау туралы» Жарлығына, Қазақстан Республикасының 2008 жылғы 4 желтоқсандағы Бюджет кодексінің 109-1 - бабына, Қазақстан Республикасының 2001 жылғы 23 қаңтардағы «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Заңының 6-бабы 1-тармағының 1) тармақшасына сәйкес, Алтай ауданының мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

> *Ескерту. Кіріспе жаңа редакцияда - Шығыс Қазақстан облысы Алтай ауданы мәслихатының 27.03.2019 № 46/3-VI шешімімен (01.01.2019 бастап қолданысқа енгізіледі).*

1. 2019-2021 жылдарға арналған Жаңа Бұқтырма кентінің бюджеті тиісінше 1, 2 және 3 - қосымшаларға сәйкес, оның ішінде 2019 жылға мынадай көлемде бекітілсін:

   1) кірістер – 42124 мың теңге, соның ішінде:

      салықтық түсімдер – 29597 мың теңге;

      салықтық емес түсімдер – 1349 мың теңге;

      негiзгi капиталды сатудан түсетiн түсiмдер – 0 теңге;

      трансферттер түсімі – 11178 мың теңге;

   2) шығындар – 42124 мың теңге;

   3) таза бюджеттік кредиттеу – 0 теңге, соның ішінде:

      бюджеттік кредиттер – 0 теңге;

      бюджеттік кредиттерді өтеу – 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо – 0 теңге, соның ішінде:

      қаржы активтерін сатып алу – 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер – 0 теңге;

   5) бюджет тапшылығы (профициті) – 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) – 0 теңге.

2. 2019 жылға арналған Жаңа Бұқтырма кентінің бюджетінде аудандық бюджеттен 847 мың теңге сомада субвенциялар көлемі қарастырылсын.

3. 2019 жылға арналған Жаңа Бұқтырма кентінің бюджетінде облыстық бюджеттен 10000 мың теңге сомада нысаналы ағымдағы трансферттер көлемі қарастырылсын.

4. 2019 жылға арналған Жаңа Бұқтырма кентінің бюджетінде 331 мың теңге сомада республикалық бюджеттен нысаналы ағымдағы трансферттер көлемі қарастырылсын.

5. Осы шешім 2019 жылғы 1 қаңтардан бастап қолданысқа енгізіледі.
