# 2019-2021 жылдарға арналған Соловьево ауылдық округінің бюджеті туралы

Қазақстан Республикасының 2008 жылғы 4 желтоқсандағы Бюджет кодексінің 9-1- бабының 2- тармағына, 75 – бабының 2- тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңының 6-бабы 1-тармағының 1) тармақшасына сәйкес, «2019-2021 жылдарға арналған Зырян аудандық бюджеті туралы» Зырян ауданының мәслихатының 2018 жылғы 21 желтоқсандағы № 41/2- VІ шешімі (нормативтік құқықтық актілердің мемлекеттік тіркеу Тізілімінде № 5-12-181 тіркелген) негізінде, Зырян ауданының мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. 2019-2021 жылдарға арналған Соловьево ауылдық округінің бюджеті тиісінше 1, 2 және 3 - қосымшаларға сәйкес, оның ішінде 2019 жылға мынадай көлемде бекітілсін:

   1) кірістер – 34258 мың теңге, соның ішінде:

      салықтық түсімдер – 5494 мың теңге;

      салықтық емес түсімдер – 55 мың теңге;

      негiзгi капиталды сатудан түсетiн түсiмдер – 0 теңге;

      трансферттер түсімі – 28709 мың теңге;

   2) шығындар – 34258 мың теңге;

   3) таза бюджеттік кредиттеу – 0 теңге, соның ішінде:

      бюджеттік кредиттер – 0 теңге;

      бюджеттік кредиттерді өтеу – 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо – 0 теңге, соның ішінде:

      қаржы активтерін сатып алу – 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер – 0 теңге;

   5) бюджет тапшылығы (профициті) – 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) – 0 теңге.

2. 2019 жылға арналған Соловьево ауылдық округінің бюджетінде аудандық бюджеттен 18443 мың теңге сомада субвенциялар көлемі қарастырылсын.

3. 2019 жылға арналған Соловьево ауылдық округінің бюджетінде облыстық бюджеттен 10000 мың теңге сомада нысаналы ағымдағы трансферттер көлемі қарастырылсын.

4. 2019 жылға Соловьево ауылдық округінің бюджетінде республикалық бюджеттен 266 мың теңге сомада нысаналы ағымдағы трансферттер көлемі қарастырылсын.

5. Осы шешім 2019 жылғы 1 қаңтардан бастап қолданысқа енгізіледі.
