# Об утверждении стипендий Акима области

> *Сноска. Утратило силу решением акима ВКО от 24 сентября 2004 года N 100.*

В целях поощрения наиболее одаренной студенческой молодежи, обучающейся в государственных высших учебных заведениях Восточно-Казахстанской области:

<a id="p1"></a>

1. Учредить стипендию Акима области на 1998 год для двух студентов Восточно-Казахстанского Государственного Университета.

<a id="p2"></a>

2. Учредить стипендию Акима области на 1998 год для трех студентов Восточно-Казахстанского Технического Университета.

<a id="p3"></a>

3. Учредить именную стипендию "Об увековечении памяти писателя О.Бокеева" на 1998 год для одного студента Восточно-Казахстанского Государственного Университета.

<a id="p4"></a>

4. Учредить именную стипендию имени Народного учителя СССР К.Нургалиева на 1998 год для одного студента Восточно-Казахстанского Государственного Университета.

<a id="p5"></a>

5. Областному финансовому управлению (Курмангалиев А.А.) выделить необходимые ассигнования на выплату стипендий на 1998 год за счет резервного фонда Акима области.

<a id="p6"></a>

6. Контроль за исполнением настоящего распоряжения возложить на заместителя Акима области Абайдильдина Т.Ж.

**Аким Восточно-Казахстанской Области**
