# Түкүл, Ұзын-Бұлақ, Сартымбет ауылдарының көшелеріне атау беру туралы

Қазақстан Республикасының 2001 жылғы 23 қаңтардағы «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Заңының 35-бабының 2-тармағына, Қазақстан Республикасының 1993 жылғы 8 желтоқсандағы «Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы» Заңының 14-бабының 4)-тармақшасына сәйкес, Түкүл, Ұзын-Бұлақ, Сартымбет ауылдарының тұрғындарының пікірін ескере отырып, ШЕШЕМІН:

<a id="para_1"></a>

1. Түкүл ауылындағы атаусыз көшесіне «Ақ бұлақ» атауы берілсін.

<a id="para_2"></a>

2. Ұзын-Бұлақ ауылындағы атаусыз көшесіне «Ынтымақ» атауы берілсін.

<a id="para_3"></a>

3. Сартымбет ауылындағы атаусыз көшесіне «Батхолла» атауы берілсін.

<a id="para_4"></a>

4. Осы шешiмнiң орындалуын бақылау бас маман Н. Сеитпаковаға жүктелсiн.

<a id="para_5"></a>

5. Осы шешім алғаш ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Округ әкімі**

**С. Калелова**
