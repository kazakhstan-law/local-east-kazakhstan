# Шемонаиха ауданы бойынша сайлау учаскелерін құру туралы

Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі «Қазақстан Республикасындағы сайлау туралы» Конституциялық Заңының 23-бабына, Қазақстан Республикасының 2016 жылғы 06 сәуірдегі «Құқықтық актілер туралы» Заңының 27-бабына сәйкес, Шемонаиха ауданының әкімі ШЕШТІ:

1. Шығыс Қазақстан облысы Шемонаиха ауданы бойынша сайлау учаскелері осы шешімнің қосымшасына сәйкес құрылсын.

2. «Шемонаиха ауданы бойынша сайлау учаскелерін құру туралы» Шемонаиха ауданы әкімінің 2018 жылғы 05 қарашадағы № 04 шешімінің күші жойылды деп танылсын (нормативтік құқықтық актілерді мемлекеттік тіркеу Тізілімінде 5-19-196 нөмірімен тіркелген).

3. Осы шешімнің орындалуын бақылау аудан әкімі аппаратының басшысы Л.Е. Марченкоға жүктелсін.

4. Осы шешім оның алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.
